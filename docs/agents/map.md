# Repository map

What lives where, and the rules for assets. Read it before adding a file, a folder or an asset.

## Repository map

```
Cargo.toml, clippy.toml, rustfmt.toml   workspace, profiles (incl. wasm-release), lint and format settings
README.md, LICENSE-MIT, LICENSE-APACHE  what the game is, how to build it; code is MIT OR Apache-2.0
.github/workflows/ci.yml                fmt, clippy -D warnings, tests, the wasm build
docs/                                   the design (`AGENTS.md`, "The bible wins")
scripts/build-web.sh                    browser build into website/play/
website/index.html, website/assets/     the French landing page and its images
website/play/                           generated by build-web.sh, except index.html; the landing page takes its
                                        fonts from here, so it shows unstyled until the build has run
game/src/                               the game, one folder per feature (below)
game/tests/structure.rs                 the 200-lines-per-file check
game/assets/                            what the game loads (below)
screenshots/, .taste-skill/, .impeccable/   local only, ignored by git
../Hachures-asset-library/              outside the repo: the full asset packs, same layout as game/assets/
```

`game/src/`, in layer order (see `code-structure.md`):

| Module | Job |
|---|---|
| `schedule.rs` | when systems run: the three `Step`s of a frame, and the `Screen` that is up |
| `settings/` | the player's settings, their file, and putting them into effect (window, sound, render, UI scale) |
| `level/` | one level: the `Level` resource, its data files, waves, story notes and choices, the world's event |
| `campaign/` | the save, and loading a level (`LoadLevel`) |
| `map/` | the terrain: the grid, species and their flow fields, the blocks, props and landing on screen |
| `ink/` | Nève's tools: the selection, the click that inks, le Droit de Passage (`passage.rs`), Biffer (`biffer.rs`), the overlay, the ghost |
| `combat/` | towers, enemies and their figurines (`combat/figure/`), waves sent, shards, la Grande Chaîne |
| `overworld/` | les Marches and the Grand Plan: terrain, sheets, road, Nève's walk, the camera rig, clouds, trips |
| `ui/` | what the player reads during play: label, margin notes, tool bar, place names, the end-of-level page; `widgets` is the shared UI toolkit, `scrollbar` its ink scrollbar; `perf` the performance overlay (F3, every screen); `studio` films the tools' pieces and the species' figurines into the pictures the bar and the Lexique show |
| `menu/` | the screens around play: splash, title, pause, settings page, sceaux tree, carnet, Lexique, controls, credits |
| `look/`, `theme.rs`, `storage.rs`, `i18n.rs` | toolkit: ink material and camera, palette and fonts, saved files, words |
| `shot/` | the dev harness (see `dev-tools.md`) |

`game/assets/`:

| Folder | Loaded | Holds |
|---|---|---|
| `data/` | compiled in (`include_str!`) | `levels/`, `worlds/`, `i18n/`, `species.ron`, `towers.ron`; editing one needs a rebuild |
| `CREDITS.md` | compiled in | every asset's author, licence and source; shown on the Credits page |
| `models/` | runtime | Kenney `.glb` models and their `Textures/colormap.png` |
| `audio/` | runtime | `music/`, `sfx/impact/`, `sfx/foley/` |
| `fonts/` | runtime | IM Fell English, Atkinson Hyperlegible Next, their OFL texts |
| `shaders/` | runtime | `hachure.wesl` (the engraving material), `paper.wesl` (the paper pass) |
| `ui/` | runtime | drawn 2D art: the travel clouds (AI-generated) and the counter icons `icon-{sepia,cible,noms,vague}.png` (vector, sources in the asset library); a missing image falls back to plain text or paper |

## Assets

- `game/assets/` keeps only what the game loads; the rest of each pack stays in `../Hachures-asset-library/`.
- Every asset has a row in `game/assets/CREDITS.md` (author, licence, source); AI-generated art says so.
- `build-web.sh` copies the runtime folders whole: a new runtime folder must be added to its `cp` line.
- Our own files are kebab-case; third-party files keep their pack's names. Sounds are grouped by kind (`sfx/impact/`, `sfx/foley/`).
